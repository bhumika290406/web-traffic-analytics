# Web Traffic Analytics 📊

## 📌 Project Overview

Web Traffic Analytics is a data analysis project focused on understanding website traffic, user engagement, conversion performance, and landing-page drop-offs.

The project analyzes web traffic data to identify important business insights and provide data-driven recommendations for improving website performance and user conversion.

## 🎯 Objectives

- Analyze website traffic sources
- Calculate Bounce Rate
- Calculate Average Session Duration
- Analyze Pageviews
- Compare conversion rates by traffic source
- Analyze the registration conversion funnel
- Identify landing pages with higher drop-off rates
- Generate actionable business recommendations

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab
- Data Analysis
- Data Visualization

## 🔍 Analysis Performed

### 1. Traffic Source Analysis

Traffic sources were compared based on:

- Number of visits
- Average session duration
- Average pageviews
- Conversion rate
- Bounce rate

Instagram achieved the highest conversion rate at **23.66%**, followed closely by Email at **23.62%**.

### 2. Conversion Funnel Analysis

The registration funnel was analyzed from initial website visits to completed registrations.

**900 Visits → 277 Registration Starts → 166 Registered Users**

This helps identify opportunities for improving the registration process.

### 3. Landing Page Analysis

Landing pages were analyzed to identify pages with higher bounce rates.

The `/verify` page had the highest bounce rate at **7.91%**, followed by the homepage `/` at **7.45%**.

### 4. User Engagement Analysis

Session duration and pageviews were analyzed to understand how users interact with the website.

The average session duration was approximately **4.06 minutes**, with an average of **3.45 pageviews per visit**.

## 💡 Key Insights

- Overall website bounce rate was relatively low at **4.89%**.
- Instagram generated the highest conversion rate.
- Email traffic also showed strong conversion performance.
- Google Organic generated the highest number of visits but had a comparatively lower conversion rate.
- The `/verify` landing page showed the highest bounce rate.
- Improving the registration funnel could increase overall conversions.

## 🚀 Business Recommendations

1. Optimize Google Organic landing pages to improve conversion.
2. Investigate the `/verify` page to reduce bounce rate.
3. Continue investing in high-performing sources such as Instagram and Email.
4. Simplify the registration process to improve completion rate.
5. Monitor traffic source and landing page performance regularly.
